KANE PLOTTER PACKAGE
====================

FILES
-----
cin-plotter.css
    Shared externally hosted stylesheet.

kane-plotter-post.txt
    Jcink post code for Kane Everett Peltier.

USING IT
--------
1. Upload cin-plotter.css to your GitHub repository.

2. Replace YOUR_CSS_URL_HERE in kane-plotter-post.txt with a direct CSS URL.

   Example GitHub Raw URL:
   https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/cin-plotter.css

   Example jsDelivr URL:
   https://cdn.jsdelivr.net/gh/USERNAME/REPOSITORY@main/cin-plotter.css

3. Paste the contents of kane-plotter-post.txt into the Jcink post.

4. The group is controlled by the outer class, for example:
   <div class="cin-plotter SAMROCK">

NOTES
-----
- No HTML comments are included in the Jcink post.
- Connections use full-width panels with internal scrolling after 115px.
- Leather background: https://i.imgur.com/YdjlC3W.png
- The username tag is intentionally outside [dohtml] so Jcink can process it:
  @[Kane Everett Peltier]
- The CSS includes fallback colors for the group classes already established on SAMWASH.
